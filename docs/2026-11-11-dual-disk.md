# 1.1.2 双硬盘温度

多块硬盘各自保留设备标识、型号、主温度来源和读数，按设备标识排序，温度变化不改变显示顺序。原 DiskTemp/DiskSensor 汇总字段继续兼容旧诊断，界面以逐盘数据为准。

- 单盘保留原任务栏布局；双盘增加独立硬盘列，上下显示硬盘1、硬盘2。有 GPU 时四列，无 GPU 时三列；内存列下行留空。
- 磁盘列宽104逻辑像素；整体宽度有GPU为356、无GPU为272，保持两行和原字体大小。
- 设置页同一行显示CPU、GPU、内存、硬盘1、硬盘2五张等宽卡片。两块硬盘标题、温度字号和层级一致，型号位于各自卡片下方；窄卡片可省略型号，完整型号在传感器详情中显示。数值字号按统一100°C参考宽度适配，单盘仍为四张卡片。
- 缺失、更新失败或过期的温度显示`—`，不会复用另一块盘的读数。超过两块时任务栏和卡片显示前两块，传感器详情保留全部。
- 编号是程序内顺序，不保证对应Windows磁盘管理编号。存储设备在采集器启动时枚举，新接入硬盘后需要重启助手。
